# Security policy

If you find a way to make installguard miss a malicious package, or a vulnerability in installguard itself, please **don't open a public issue**. Use GitHub's [private vulnerability reporting](https://github.com/iambazzy/installguard/security/advisories/new) or email mohammadbasit0404@gmail.com.

You'll get a reply within a few days. Fixes go out as a patch release, with credit to you if you'd like.

installguard is a safety net, not a guarantee. It checks public metadata and can't detect every malicious package, especially a trusted package that has been compromised.
